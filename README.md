# Blinkit Sales Analysis Dashboard

## Project Overview
This project analyzes Blinkit sales data to understand product performance, outlet performance, customer ratings, and sales trends. An interactive Power BI dashboard was created to track key business KPIs and generate useful insights for decision-making.

## Tools Used
- Power BI
- Excel / CSV
- Data Cleaning
- DAX
- Data Visualization

## Key KPIs
- Total Sales: $1.20M
- Average Sales: $141
- Number of Items: 8,523
- Average Rating: 3.9

## Dashboard Insights
- Total sales reached $1.20M across all outlets.
- Tier 3 outlets generated the highest sales contribution.
- Supermarket Type 1 had the highest total sales.
- Fruits, snack foods, and household items were among the top-selling categories.
- Medium outlet size contributed the highest sales compared to small and high-size outlets.

## Project Features
- KPI cards for sales, average sales, item count, and rating
- Sales trend by outlet establishment year
- Sales analysis by outlet size, location, and type
- Item type performance comparison
- Interactive filters for outlet size, location type, and item category

## Conclusion
This dashboard helps identify sales performance patterns, top product categories, and outlet-level business performance. It can support better inventory planning, sales strategy, and business decision-making.
