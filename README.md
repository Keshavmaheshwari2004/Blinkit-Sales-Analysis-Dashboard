# BlinkIT Grocery Sales Analysis

## 📊 Project Overview

This project performs an **exploratory data analysis (EDA)** of BlinkIT grocery sales data using **Python, Pandas, NumPy, Matplotlib, and Seaborn**.

The objective is to analyze sales performance across products, item categories, fat content, outlet types, outlet locations, outlet sizes, and establishment years, and to identify key business insights from the data.

---

## 🎯 Objectives

* Understand the structure and characteristics of the BlinkIT grocery dataset
* Clean and prepare the data for analysis
* Calculate important sales KPIs
* Analyze sales by item type and fat content
* Compare sales across different outlet types and locations
* Identify top-performing products and outlets
* Analyze relationships between product attributes and sales
* Generate business insights from the analysis
* Export analysis results to Excel

---

## 🗂️ Dataset

The dataset contains **8,523 records and 12 columns** related to grocery products and outlet performance.

### Main Columns

| Column                      | Description                         |
| --------------------------- | ----------------------------------- |
| `Item Identifier`           | Unique product identifier           |
| `Item Fat Content`          | Fat-content category of the product |
| `Item Type`                 | Product category                    |
| `Item Weight`               | Product weight                      |
| `Item Visibility`           | Visibility of the product           |
| `Sales`                     | Sales generated by the product      |
| `Rating`                    | Product rating                      |
| `Outlet Identifier`         | Unique outlet identifier            |
| `Outlet Establishment Year` | Year the outlet was established     |
| `Outlet Location Type`      | Outlet location classification      |
| `Outlet Size`               | Size of the outlet                  |
| `Outlet Type`               | Type of outlet                      |
